# Roadmap

## Phase 1: MVP

- Browser DOM scanner.
- Backend analysis API.
- Heuristic AI pipelines.
- Explainable report schema.
- Dashboard history view.
- Docker Compose stack.

## Phase 2: Model Integration

- Add ONNX image detector.
- Add text transformer classifier.
- Add audio spectrogram CNN.
- Add video frame sampler and temporal worker.
- Store evidence artifacts in object storage.

## Phase 3: Security Product

- Tenant auth and policy controls.
- Privacy modes and local inference.
- Signed tamper-evident logs.
- Admin dashboard.
- Alert routing and SIEM export.

## Phase 4: Scale

- Dedicated inference workers.
- GPU scheduling.
- Model registry.
- Drift monitoring.
- Human review workflow.
